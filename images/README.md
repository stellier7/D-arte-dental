# Imágenes — D'Arte Dental

Sube las fotos con **estos nombres exactos** para que aparezcan automáticamente en el sitio.

## Cómo subir

1. Ve a: **https://github.com/stellier7/D-arte-dental/upload/main**
2. Arrastra los archivos a la carpeta correcta (o usa "Add file" → "Upload files").
3. Haz commit con un mensaje como `Agregar fotos de la clínica`.

## Archivos requeridos

| Archivo | Ubicación | Uso en el sitio |
|---------|-----------|-----------------|
| `hero-main.jpg` | `images/hero/` | Foto principal del hero (recomendado: retrato vertical, mín. 900×1200 px) |
| `team-photo.jpg` | `images/` | Foto del equipo / doctor(a) en la sección "El equipo" |
| `recepcion.jpg` | `images/gallery/` | Galería — recepción |
| `consultorio.jpg` | `images/gallery/` | Galería — consultorio |
| `equipo-medico.jpg` | `images/gallery/` | Galería — equipo médico |
| `doctor.jpg` | `images/gallery/` | Galería — foto del Dr./Dra. |
| `caso-antes-despues.jpg` | `images/gallery/` | Galería — caso antes/después |
| `fachada.jpg` | `images/gallery/` | Galería — fachada / Centro Morazán |
| `detalle-tratamiento.jpg` | `images/gallery/` | Galería — detalle de tratamiento |
| `sonrisa-paciente.jpg` | `images/gallery/` | Galería — sonrisa de paciente |

**Total: 10 fotos** (2 principales + 8 de galería)

## Recomendaciones

- Formato: JPG o WebP
- Tamaño: entre 1200 px y 2000 px de ancho
- Peso: idealmente menos de 500 KB por imagen (comprime antes de subir)
- Usa nombres en minúsculas y con guiones, tal como aparecen arriba
